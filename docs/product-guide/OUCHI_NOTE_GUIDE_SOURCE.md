# おうちノート 利用ガイド

家族が毎日使う時の操作を説明します。2026年10月10日の改善ブランチに対応しており、本番反映前は実際の画面と異なる場合があります。

技術仕様は[Requirements & UX Baseline](../requirements/FAMILY-OPS-REQUIREMENTS-UX-BASELINE.md)、[現在の設計](../design/current/)、Accepted ADRを参照してください。最初の説明には[パートナー向け3分ガイド](OUCHI_NOTE_PARTNER_QUICKSTART.md)を使えます。

## 何のために使うか

今日の担当、予定、例外、お願いの合意、実際に済んだことを共有するためのアプリです。直接伝えると強い言葉になりそうな依頼は、AIで伝え方を整理し、確認した内容を相手に見せて調整できます。

家事を採点したり、パパとママの勝敗を決めたりするものではありません。予定担当と実際にやった人を別々に残します。後から定例を変更しても、過去の実績は変わりません。

## 最初に使う

1. 自分のメールアドレスで登録・ログインします。
2. 家庭を作ります。
3. 最低限から始めたい場合は「今日から使う」。送り迎えや通知の細かい設定は、後から続けられます。
4. 「設定」の「家族」からパートナー招待を作り、リンクを共有します。パートナーは自分のアカウントで参加します。
5. 「通知・LINE連携」でLINEとの連携を確認します。連携の期限が切れた場合は、コードを発行し直します。

招待リンクをなくした時は、設定から発行し直せます。発行し直すと古い未使用リンクは使えなくなるため、確認してから新しいリンクを共有します。

ログイン画面の「パスワードを忘れた場合」から再設定メールを送れます。メールのリンクを開き、新しいパスワードを2回入力します。

## 「今日」の使い方

予定と自分の作業は、時間帯が変わっても同じ順に表示します。

1. **先に決めること** — 返事や確認が必要なお願いなど。
2. **いつもと違うこと** — 今日の例外。平日に毎日は出ない準備には印も付きます。
3. **今日の予定** — 時刻や行事を確認します。
4. **自分のやること** — 持ち越し、朝、日中、夜の順で確認します。
5. 入力、待ち、未読の引き継ぎ、相手側の重要な情報。
6. **余裕があれば**と完了済みの作業 — 必要な時だけ開きます。
7. **明日の準備・引き継ぎ**と買い物。

該当する情報がない欄は省略します。日中の「次にやること」には、その時間帯の作業を表示します。残っている朝の作業は「朝の残り」で確認できます。

前日・翌日に移ると、選んだ日の予定と実績・やることを確認できます。過去や未来の日は、現在時刻の入力案内や「明日」の欄とは分けて扱います。

通信に失敗した時は、予定がない・担当が未定とは判断しません。取得できなかった案内、または最後に読み込んだ内容であることを表示します。

## 完了・実績を記録する

「✓ 完了」で自分が終えたことを記録します。行が消えても、直後の通知にある「元に戻す」から戻せます。相手がその後に変更していた場合は、最新の内容を上書きせず、再確認が必要になります。

その作業の「•••」から、できなかった、相手が完了、今回は不要、待ち、修正などを選びます。相手が担当する作業には、その担当者の完了操作も表示します。2人で対応した場合も、同じ作業を2件完了した扱いにはしません。

| 結果 | 意味 |
| --- | --- |
| 完了 | 必要な対応を終えた |
| できなかった | 必要だったが実行できなかった |
| 今回は不要 | その回だけ不要だった |
| 期限終了 | その回の実行期限が終了した |
| 待ち | 問い合わせなどの返答を待っている |
| 中止 | 実行すること自体を取り消した |

まとめて入力する画面では「全部やった」「大体やった」「個別で答える」を選べます。「大体やった」は、個別の結果を勝手に全部完了にしません。「余裕があれば」の作業もまとめて完了する対象には含めません。

## お願い・相談

「お願い」から内容を入力します。自分用の入力をAIでやわらかく言い換え、相手へ送る文面を確認・編集します。返事がほしい期限と、作業そのものの期限は別々に設定できます。送信前の確認画面から送ります。

軽いお願いには「やる」「難しい」「その他の返答」が出ます。担当変更のお願いには「引き受ける」「難しい」「相談する」が出ます。「引き受ける」では、対象の日と作業、担当の変更、一緒に変わる当日の家事を確認します。確認内容を取得できない時は確定できません。

相談したい時は、まず「相談する」を選びます。自分の気持ちや難しい条件は「相手には送りません」の欄へ入力し、AIの提案を作れます。自分用の入力は、相手への提案文にはそのまま含めません。AIの提案は編集できます。外部AIサービスへの処理は、AIのボタンを押した時に行います。

送る文面と具体的な期限を確認し、「この文面・条件で提案する」を押します。**二人が同じ変更案を確認して初めて反映します。**片方だけの確認、AIの提案、メモの編集だけでは担当や予定は変わりません。変更案を編集すると、以前の案への確認は無効になります。

「今週だけ」の担当変更は対象をまとめて扱います。個別の時刻を変える場合は、その日の予定から相談します。すでに口頭で合意した変更は、対象の担当変更から「調整済み」として登録できます。

## 定例の内容と担当を直す

「設定」→「いつもの担当」で変更します。

- **定例の名前・チェック項目** — 朝・夜の定例を選び、名前や項目、必須かどうかを直します。次に作られる定例から反映します。
- **送り・お迎え** — 開始日、曜日ごとの担当と時刻を編集し、1週間の内容を確認して保存します。現在の期間と開始予定の期間を区別して表示します。
- **家事・朝の準備** — 曜日、担当、準備の項目を設定します。定例を追加する入口もあります。

変更しても過去の実績は保たれます。個別に合意した担当も、自動で上書きしません。見直しが必要な場合は二人で確認します。通信に失敗した場合は、入力を保ち、登録内容を再確認できます。

「設定」の「家族」でパパ／ママの表示を変更する時は、変更内容を確認して保存します。選択しただけでは保存しません。

## 追加する・質問する

右下の「＋」から、そのまま文章で入力できます。AIが予定、やること、お願い、買い物、共有、実績の候補を整理します。

候補を1つの確認画面で見て、不要なものを外し、違うところだけ編集します。お願いの文面や重複候補は、必要な確認を済ませてから登録します。失敗した候補だけ再試行できます。

「明日の予定は？」などの質問では、対象の日の予定・作業を読み取って表示します。質問するだけで予定や担当は変更しません。

## 買い物

「買い物」で品名を追加します。担当を決めるか、「誰でもOK」を使えます。「自分がやる」を選ぶと対応中になり、二重購入を減らせます。

お店で買った品は「購入した」。購入方法が未定でも、お店で買った記録をすぐ付けられます。通販は「注文した」と「届いた」を分けます。

複数の商品を買った時は「買ったものをまとめて記録」で買った品だけを選びます。選ばなかった品は残ります。一部の保存に失敗した時は、成功したものと失敗したものを分けて表示します。1商品の数量の一部だけを購入した記録は、このまとめ操作の対象外です。

## 行事・明日の準備・共有

「今日」の「明日の準備・引き継ぎ」から持ち物や提出物を追加できます。

家庭の行事は、予定のリンクから詳細を開きます。行事に紐づく準備の担当、日付、期限、チェック項目を確認・編集できます。AIの準備案は、人が確認してから登録します。

作業の依頼ではなく、相手に知ってほしい情報は「共有」。未読の引き継ぎは「今日」に出ます。「確認した」で読んだことを記録できます。

問い合わせ済みなら作業を「待ち」にし、次に確認する日を設定します。毎日の未完了作業とは分け、確認日になった時に再表示します。

## 子ども・園・学校とおたより

「設定」→「子ども・園・学校」で、子どもの名前、園・学校、クラス、適用期間、おたよりで使う別名を登録します。

進級や転園では、前の期間の終了日を編集してから、新しい期間を追加します。過去のおたよりの対象を残せます。

画像はLINEのトークへ送って取り込みます。アプリでは取り込まれた候補の内容、対象の子ども、日付や曜日を確認・編集します。対象が未登録なら、候補から設定へ進んで戻れます。今回の改善ではアプリから直接画像をアップロードする入口は追加していません。

おたよりに明記された内容とAIの提案を区別し、必要な候補だけ登録します。AIだけで担当、日時、中止を確定しません。元画像を削除しても、登録済みの予定や履歴は残ります。外部の画像処理が利用できるかは、家庭の提供状態によります。

## 履歴と通知

「履歴」で直近2週間、30日、90日、または任意の期間を選べます。作業名で絞り込めます。見出しは作業の対象日です。実際に記録した日時は詳細で確認できます。以前の記録を修正する場合も、対象の日を開いてから直します。

LINEとアプリは同じ家庭のデータを参照します。通知が来ない時は「通知・LINE連携」で家族それぞれの連携状態と通知設定を確認してください。通常の家事完了を、毎回相手に通知する運用にはしません。

Google予定は、確定した家庭の内容を勝手に上書きしません。外部からの変更は比較して確認します。家庭からGoogleへ書き出す機能の有効化は別途管理されます。

1人テストモードは「設定」→「安全に使い方を試す」にあります。テスト相手への合意を、本物のパートナーの同意として扱いません。

## ガイドの更新

画面の名前と操作は実装と一緒に更新します。家族向けPDFや正式なスクリーンショットは、本番反映後にiPhone・PWA・LINEの実画面を確認してから作成します。今回のブラウザ確認に使った情報は架空の家庭データです。
