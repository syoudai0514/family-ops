# おうちノート — パートナー向け3分ガイド

## まずこれだけ

おうちノートは、家事や育児を採点するためのアプリではありません。

**今日だれが何をするか、いつもと違うこと、お願いが決まったか、もう誰かが済ませたかを、言わなくても分かるようにするアプリ**です。

毎日細かく入力する前提ではありません。基本は朝と夜に要点を見るだけです。

---

## 毎日の使い方

### 朝

LINEの朝通知かPWAの`今日`を見ます。

先に出るのは:

- 🔴 返事や判断が必要なもの
- ⚠️ 今日だけ違うこと
- ℹ️ 引き継ぎ
- ✅ もう相手が済ませてくれたため、自分はやらなくてよいもの
- 今日の自分のタスク

通常の家事を相手が終えただけで、いちいち「○○がやってくれました！」という通知は来ません。

### 日中

必要な時だけ使います。

- 相手からお願いが来た → `やる / 難しい / その他の返答`
- 自分がやれそうな`誰でもOK` → `自分がやる`
- 終わった → 完了
- 問い合わせ済みで返事待ち → `待ち`
- 買い物した → 購入済み

### 夜

残っている大事なものを確認します。

実績入力は、忙しさに合わせて:

- `全部やった`
- `大体やった`
- `個別で答える`

から選べます。

`大体やった`を選んでも、細かい項目を勝手に全部完了扱いにはしません。

---

# お願いされた時

最初に選ぶのは:

- `やる`
- `難しい`
- `その他の返答`

です。

### やる

その内容で合意します。必要な実行タスクが作られます。

### 難しい

担当は勝手に変わりません。

### その他の返答

「確認してみる」「18:30ならできる」など、調整できます。

条件付きで相談した場合、**片方がOKしただけでは担当変更になりません**。同じ条件を双方が確認して初めて確定します。

---

# 予定と実際は別

たとえば:

- 予定: パパがお迎え
- 実際: ママがお迎え

になっても大丈夫です。

予定担当と実際にやった人を別に記録します。

あとからルールを変えても、過去の実績は書き換えません。

---

# 「誰でもOK」は便利

買い物や家事で、どちらがやってもよい時に使います。

例:

`牛乳を買う　誰でもOK`

自分がやるなら`自分がやる`。

すると相手には「対応中」と見えるので、二重に買うのを防げます。

---

# 返事待ちは「待ち」

問い合わせ済み・予約確認待ちなどは、未完了タスクのまま毎日催促されません。

`待ち`にして「次に確認する日」を設定すると、その日に再表示されます。

---

# 買い物

追加 → 必要なら担当 → 購入済み、というシンプルな流れです。

牛乳や薬など二重対応を避けたいものは、必要なら:

`牛乳の買い物は対応済みです`

のような中立通知が届きます。

---

# 園・学校のお知らせ

将来的な基本動線は:

画像を入れる
→ 書いてある内容を抽出
→ AIの提案は別表示
→ 人が確認
→ 予定や準備に登録

です。

AIが勝手に予定・担当を確定することはしません。

---

# Googleカレンダー

Google側で予定が変わっても、家庭内で確定した予定を無条件に上書きしません。

食い違った場合は、どちらを採用するか確認できる設計です。

---

# このアプリがしないこと

- 家事量でパパ・ママを採点する
- 相手の通常家事完了を毎回pushする
- 相談中なのに勝手に担当変更する
- AIの推測だけで家庭予定を確定する
- テスト操作を本物の妻の同意として扱う
- Google側の削除だけで家庭の履歴や準備実績を消す

---

# 最初の一週間はこれだけでOK

1. 朝、`今日`を見る
2. お願いが来たら返事する
3. 誰でもOKを自分がやる時はclaimする
4. 終わったものを完了する
5. 夜、必要なら`全部やった / 大体やった / 個別`

細かい設定や履歴は必要になった時だけPWAで見れば十分です。
