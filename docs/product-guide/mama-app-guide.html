おうちノート
アプリの使い方

ふだんはLINEだけで大丈夫です。
カレンダーで見たい時や、予定を直したい時にアプリを使います。

アプリでできること

  • 月・週のカレンダーで、予定と送り迎えを見る
  • 予定の日にち・時間を変える、消す
  • 送り迎えを1日だけ代わる・代わってもらう
  • お願いを送る・お願いに返事をする

もくじ

  1. アプリを開く・ホーム画面に置く ……… 2ページ
  2. ログインする（はじめての時） ……… 2ページ
  3. 画面の見方・予定を見る ……… 3ページ
  4. 予定を追加する・変える・消す ……… 4ページ
  5. 送り迎えを代わる・お願いする ……… 5ページ
  6. 通知の設定・こまった時 ……… 6ページ

※ 先に「LINEのはじめかた」でLINEの連携を済ませておいてください。

1アプリを開く・ホーム画面に置く

スマホのブラウザで、次のアドレスを開きます。

family-ops-web.vercel.app

LINEの「朝のおうちノート」の下にある 「▶ 完了・詳細はここから」 のリンクからも開けます。

iPhone の場合

  1. Safari で開く
  2. 下の 共有ボタン（□に↑） を押す
  3. 「ホーム画面に追加」 → 「追加」

Android の場合

  1. Chrome で開く
  2. 右上の ︙ を押す
  3. 「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面に「おうちノート」のアイコンができます。次からはそこから開けます。

2ログインする（はじめての時）

  1. ログイン画面で 「Google でサインイン」 を押す
  2. 自分のGmail を選ぶ
  3. 「今日」の画面が出ればログイン完了

Googleで入れない時は、自分のGmailのアドレスとパスワード（パスワードはパパに聞いてください）を入れて 「メールでログイン」。

「新規登録」は押さないでください。 別の人として登録されてしまい、家族の予定が見えません。

4予定を追加する・変える・消す

➕ 追加する

下の ＋ → 「イベント・予定を追加」（やることなら「単発ToDoを追加」）。日にち・時間・内容を入れて保存します。
LINEで「12/3 14時 歯医者」と送っても追加できます。

✏️ 日にち・時間を変える

  1. 今日・週・月の画面で、変えたい予定を探す
  2. 予定の 「•••」 → 「編集」
  3. 「日付」「開始時刻」「終了時刻」を直して 「保存」

※ 「定例から作られた項目です」と出るもの（毎日の家事など）は、ここでは変えられません。パパに相談してください。

🗑 消す

予定の 「•••」 → 「削除」 → 確認が出たら OK。消すと元に戻せません（Googleカレンダーからも消えます）。
くり返しの予定は「この予定だけ削除」「これ以降をすべて削除」「すべて削除」から選べます。

別の日の予定は、月 で日にちを押して 「詳しく見る・編集」 から同じように操作できます。

5送り迎えを代わる・お願いする

🤝 もう2人で話して決めた時（すぐ変わります）

  1. 下の 月 → その日を押す
  2. 「送迎」のところの 「この日だけ変更」
  3. 「送りだけ変更する」「お迎えだけ変更する」で担当を選び、「この日だけ変更」

元に戻す時は、同じ画面の「この日の変更を削除して基本に戻す」。いつもの曜日の決まりは変わりません。

🙏 まだ話していない時（パパにお願いする）

  1. その日の送り迎えの 「•••」 → 「担当を調整」
  2. 「まだ合意していないので、お願いを送る」 を選ぶ（ひとこと添えてもOK）
  3. 「お願いを送る」 → パパのLINEに届きます

週の画面の 「担当を相談」 からも送れます。パパが引き受けるまで、担当は変わりません。

📩 お願いを送る・返事をする

送る：＋ → 「お願いを送る」 → 「+ お願いを送る」 → 内容を入れて 「送信内容を確認」 → 「LINEで送る」
返事：お願いの画面の 「受け取ったお願い」 で、「引き受ける」「やる」「難しい」「相談する」 から選ぶ
LINEに届いたお願いのボタンで返事をしても同じです。

6通知の設定

右上の ⚙ → 「通知・LINE連携」 で確認・変更できます。

  • LINE連携：「ママ：LINE連携済み」になっていればOK
  • この端末への通知：「この端末で通知を受け取る」 を押すと、予定の通知がスマホに直接届きます。
    iPhoneは、ホーム画面に追加したおうちノートから開いた時だけオンにできます。
  • LINEで受け取るお知らせ：種類ごとにオン・オフできます

こまった時は

ログインできない

「Google でサインイン」で自分のGmailを選んでください。それでもだめな時は、パパに見せてください。

家族の予定が見えない・「家庭を設定する」と出る

別のメールアドレスで入っている可能性があります。自分のGmailで入り直してください。

画面が古いまま

右上の「更新」を押してください。

間違えて完了・削除した

完了は「•••」→「未完了に戻す」で戻せます。削除は戻せないので、パパに伝えてください。

アプリは使いたい時だけで大丈夫です。ふだんはLINEのお知らせを見るだけでも十分です。
