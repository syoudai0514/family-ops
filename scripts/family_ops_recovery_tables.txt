# CF-11 right-sized recovery allowlist.
#
# These are durable household/domain tables that must be recoverable from the
# separate app-save-hub Supabase project. The order is also the restore order;
# keep parents before children so normal FK enforcement remains active during
# the recovery drill.
#
# Deliberately excluded:
# - auth credentials/sessions/provider tokens
# - private queues, receipts, cron/net state, webhook inboxes
# - Google/LINE connection state and provider caches
# - test/simulation data
# - transient AI/image extraction/review state
# - artifact handoff/evidence transport data
#
# Rows with a test_context_id are filtered out by the snapshot producer.
